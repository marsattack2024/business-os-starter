# Your work

This is where repeatable work for one client, case, matter, job, property, project, or engagement lives. The folder is always named `work/`; your business can use whatever plain-English label feels natural.

Use a work-item folder when you would otherwise have to explain the same background again. Keep business-wide marketing and drafts in `content/`.

## Start a work item

1. Copy `_template` and give the copy a short lowercase name with dashes, such as `smith-v-jones` or `12-oak-street`.
2. Fill in what you know. Mark claims as unverified when the source is unclear.
3. Put original material in `sources/` and finished work in `deliverables/`.
4. Keep `status.md` and `tasks.md` current.

One customer may have several work items. Never copy facts, files, permissions, or conclusions from one item into another.
