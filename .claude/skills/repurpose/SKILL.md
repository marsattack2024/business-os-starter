# Repurpose

One good piece becomes a week of posts. The idea stays the same; the shape changes per platform.

## Read first

- The piece being repurposed — usually a file in `content/`, or something the owner pastes in
- `context/voice.md` — every version has to sound like them
- `context/customers.md` — who each version is talking to

## Steps

1. Ask which platforms, unless the owner already said. Offer the ones that fit their business rather than all of them.

2. Pull the **three strongest moments** out of the original: the best story, the most surprising line, the most useful takeaway. These become the spines. If you can't find three, the original only supports one or two derivatives — say so instead of padding.

3. Write each version natively:
   - **Instagram / Facebook** — one moment, short lines, ends with something to say back
   - **LinkedIn** — the takeaway, one concrete example, no hashtag pile
   - **Short video script** — first line is the hook, 30–60 seconds spoken aloud, written the way people talk
   - **Email** — one moment, one link back to the original
   - **Newsletter blurb** — three sentences and the link

4. Never paste the same text twice with different line breaks. If two versions read the same, cut one.

5. Show the owner all versions in one message so they can see the set.

## Save it

`content/YYYY-MM-DD-repurposed-<topic>.md` — one file, all versions, each under a clear heading with the platform name.

## Done when

- Each version reads like it was written for that platform first.
- Every claim traces back to the original piece — nothing new was invented on the way.
- The file is saved and the owner has seen it.
