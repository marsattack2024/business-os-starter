# Plan Business Goals

Read `connections/agentsfirst.md`, `context/business.md`, and
`context/goals.md`. Start with the owner's intended outcome, deadline, and
evidence of progress; do not invent metrics or commitments.

Create a concise proposal: one outcome, a few measurable key results, the
first action, and any assumptions. Save it locally under
`content/YYYY-MM-DD-goal-proposal.md` until the owner accepts it.

When connected, use live discovery and `lookup_okrs` to understand the goals
already recorded. The external accountability connection may update progress
on an existing key result with `update_kr_progress` when that tool and schema
are available. It does **not** authorize creating or replacing an entire OKR
tree. Do not claim a proposal was remotely saved unless the live response
proves the permitted update succeeded.

If no remote write is available, keep the proposal marked `Status: UNSYNCED`
and tell the owner exactly what remains local.
