# Video Analysis Output Format

Use this structure when the user wants durable notes rather than an informal
discussion.

```markdown
# <Video title>

Source: <canonical URL>
Platform: youtube | tiktok | instagram
Timed caption source: creator | automatic | platform | unavailable
Post text source: platform description | public HTML meta description | unavailable

## [00:07:10] Human/Machine toggle

Spoken evidence: <brief paraphrase of the caption>

Post-text evidence: <brief paraphrase of the social post caption, if relevant;
never present this as speech>

Visual evidence: The decoded frame at 00:07:10.042 shows <direct observation>.

Inference: <clearly labelled design interpretation>
```

Keep quotes short. A caption timestamp is not proof of an on-screen detail; a
frame is not proof of what was said. Use both when making a combined claim.
