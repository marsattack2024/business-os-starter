# Method provenance

`prototype-an-idea` adapts the question-first, disposable-prototype method from
Matt Pocock's MIT-licensed `prototype` skill, reviewed at source commit
`885e2ca4d842d139e9aef4e48d366c63cb1b8013`:

<https://github.com/mattpocock/skills/tree/885e2ca4d842d139e9aef4e48d366c63cb1b8013/skills/engineering/prototype>

Business OS changes the storage and release model for beginner owners: temporary
artifacts use the local system temp directory by default, stale branches are
not created merely to preserve experiments, and public launch is handled by a
separate skill.
