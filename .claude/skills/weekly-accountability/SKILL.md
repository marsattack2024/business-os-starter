# Weekly Accountability

Read `connections/agentsfirst.md` and the recent local accountability notes.
If connected, begin with live tool discovery and the owner’s current
accountability context rather than reconstructing a report from guesses.

Ask for a short, useful review: wins, what did not happen, the actual blocker,
and one change for next week. If the discovered contract allows it, record the
result with `log_weekly_entry`; report the returned outcome.

When the connection is not available, save the review to
`content/YYYY-MM-DD-weekly-accountability.md` with `Status: UNSYNCED`. It is a
private draft until the owner reconnects and chooses to record it remotely.

End with no more than three commitments for the next week. Do not treat CRM or
other product features as available unless live discovery grants them.
