# Public website content

Only Markdown files in this folder are available to the public website.

Do not use this as a drafting folder. Create drafts in the project-level
`content/` folder, then use the **publish this post** request once the owner
has explicitly approved the exact draft. The publishing step copies one file
here and never deploys the site.

Each published blog post needs this frontmatter:

```md
---
title: A clear, specific title
date: YYYY-MM-DD
published: true
---
```
