This file shows how a post looks after the owner explicitly publishes it. It
is the only example this starter website displays.

Drafts, plans, emails, and notes belong in the private `content/` folder at
the top of this project. The website never reads that folder.

## What to do next

Ask your employee to **write a blog post** to make a private draft. When you
approve the exact draft, ask it to **publish this post**. It copies only that
draft into this folder and builds the site to check it. Publishing prepares
the site; deployment is always a separate, explicit request.
